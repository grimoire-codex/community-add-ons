# Basic Fantasy RPG

A character sheet for the **Basic Fantasy Role-Playing Game**.

Uses the default sectioned layout rather than a custom one — the game is small
enough not to need the extra design, which is rather the point of having a
default that works.

## What it covers

- **Four classes** (Cleric, Fighter, Magic-User, Thief) and four races
- **The ability bonus table**, derived: 3 → −3 through 18 → +3
- **Ascending armour class** from worn armour, shield and Dexterity
- **The five saving throws**
- **Spells**, shown only for Clerics and Magic-Users
- **Equipment** with weight against a Strength-adjusted encumbrance threshold
